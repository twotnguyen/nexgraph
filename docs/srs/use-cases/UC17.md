# UC17 – Xem báo cáo và lập chỉ mục tài liệu

**Chức năng** F10

## Tác nhân và tiền điều kiện

Lập trình viên. Dự án đã được lập chỉ mục hoặc sẵn sàng lập chỉ mục lại với tùy chọn bổ sung.

## Luồng chính

1. Trong **Tổng quan**, dùng tùy chọn lập chỉ mục lại để chọn **Gồm tài liệu** hoặc **Gồm audio/video** theo phạm vi cần phân tích.
2. Engine trích text hoặc bản chép lời khả dụng. Các đoạn tài liệu có thể thành nút `document`, với cạnh `DOCUMENTS` tới ký hiệu được tham chiếu.
3. Mở **Báo cáo** để xem nút trung tâm, cộng đồng, liên hệ đáng chú ý và câu hỏi gợi ý. Chọn câu hỏi để xem tập nút và cạnh liên quan trên Graph. Có thể xuất báo cáo Markdown qua UC11.

## Ngoại lệ và giới hạn

- Chép lời audio/video cần phụ thuộc ngoài phù hợp. Khi thiếu công cụ hoặc chưa có transcript, ứng dụng hoặc API cần báo rõ trạng thái.
- API `/code` có đường đọc text chuyển đổi và transcript. Giao diện mở tệp hiện đi qua editor của host nên trải nghiệm xem text của tệp nhị phân còn thiếu.

## Tiêu chí nghiệm thu

Lập chỉ mục fixture có Markdown và PDF, kiểm tra nút tài liệu và cạnh liên quan rồi mở Báo cáo. Kiểm thử riêng các trường hợp media có và thiếu phụ thuộc hoặc transcript.
